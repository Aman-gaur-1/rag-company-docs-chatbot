# Company Docs Chatbot

Build a chatbot that searches three company PDFs and answers questions with file and page citations. This is Module 13 in ConsoleFlare's free Agentic AI series. You will follow the pipeline from loading PDFs to deploying a Streamlit app.

## Final result

**Question:** What is the employee leave policy?

**Answer:** Full-time employees receive 24 paid annual leave days per calendar year. **Source:** [ConsoleFlare_HR_Policy.pdf, Page 1]

## What you need

- Basic Python
- Free accounts for NVIDIA API Catalog, Pinecone, and Groq
- PyCharm and Git

## How to use these notes

Start with the architecture, then follow the numbered build pages in order. The files in this repository are the reference for what the project currently does. A few steps have issues documented in the notes, so check those before running them.
